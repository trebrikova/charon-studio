What is a UX Module?

Each module is an independent feature with a fully functional flow.It includes all the necessary decision nodes - points where the user makes a choice and takes a target action.

At the same time, these modules offer the benefit of seamless integration into the existing product flow without the need to rebuild existing functionality.
